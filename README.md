# 🏏 ESPN Cricket Data Analysis

# 📌 Project Overview
This project presents a comparative analysis of India and South Africa cricket teams using data sourced from ESPN Cricinfo.
The analysis is developed in Microsoft Power BI with a focus on batting, bowling, and fielding performance through interactive dashboards.

# 🌐 Data Source
Source: ESPN Cricinfo
Method: Web scraping using Power BI Web connector
Data extracted from structured tabular formats
Separate datasets for India and South Africa

# 📊 Report Pages
The Power BI report consists of three pages:
Batting Analysis
Bowling Analysis
Fielding Analysis

# 🛠️ Tools & Technologies
Microsoft Power BI
Power Query Editor
Power BI Web Connector
DAX (Data Analysis Expressions)

# 🔄 Data Processing & Transformation
Extracted data using Web as Data Source
Cleaned and transformed data in Power Query Editor
Implemented M language for advanced transformations
Created custom functions for reusable logic
Handled missing values and standardized columns

# 📐 DAX Functions Used
LOOKUPVALUE() – data mapping and reference lookups
RANKX() – player ranking based on performance
ABS() – absolute value calculations
Math functions such as POWER() for advanced metrics.

# 🧩 Steps Involved
Collected cricket statistics from ESPN Cricinfo using Power BI Web connector
Performed data cleaning and shaping in Power Query
Used custom M functions to automate transformations
Created calculated columns and measures using DAX
Designed interactive dashboards for batting, bowling, and fielding analysis.

# 📈 Key Insights
Comparison of top-performing batsmen from India and South Africa
Ranking of leading bowlers based on wickets and economy
Fielding efficiency comparison using catches and run-outs
Clear visibility into team-wise and player-wise performance trends

# ✅ Conclusion
This project demonstrates an end-to-end Power BI workflow, covering web data extraction, data transformation, DAX calculations, and interactive visualization, enabling effective performance comparison between India and South Africa cricket teams.
